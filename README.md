
# Random Password Generator

**Автор:** Иван Иванов (можно заменить на своё имя)

## Описание

Простое, но функциональное приложение для генерации случайных паролей с графическим интерфейсом (GUI). Позволяет настраивать длину пароля, использовать цифры, буквы и спецсимволы, а также сохранять историю сгенерированных паролей в JSON-файл.

## Возможности

- Настройка длины пароля (4–32 символа)
- Выбор типов символов: цифры, буквы, спецсимволы
- Кнопка копирования пароля в буфер обмена
- Сохранение истории паролей в `history.json`
- Загрузка истории при запуске
- Очистка истории
- Проверка корректности ввода

## Требования

- Python 3.6+
- Стандартные библиотеки: `tkinter`, `random`, `string`, `json`, `os`, `datetime`
