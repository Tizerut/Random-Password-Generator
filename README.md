## Описание программы

Expense Tracker — это desktop-приложение для учёта личных расходов. Позволяет добавлять записи о тратах, фильтровать их по категориям и датам, а также подсчитывать общую сумму расходов за выбранный период.

Программа решает проблему контроля бюджета: вы всегда видите, куда уходят деньги, и можете анализировать свои траты.

---

## Требования для запуска

- **Python 3.10** или выше
- Библиотеки (все встроенные):
  - `tkinter` — графический интерфейс
  - `json` — хранение данных
  - `datetime` — работа с датами
  - `os` — проверка файлов
